# shinx121_freecam

Lets the camera be moved independently of the player, making it easier to take screenshots, observe normally inaccessible viewpoints, etc.

## Features
- Detach the camera at any time and explore the world from new angles. This even works during cutscenes!
- Full control over the camera: move, rotate (including roll), and zoom (FOV) as needed.
- Optionally resume gameplay with a static fixed-camera.
- **(experimental)** Pause the game while retaining full camera control to view otherwise impossible angles.

## Controls
Toggle freecam:
- R-Trigger + D-Pad Up: Enter/exit freecam
- R-Trigger + Start: Enter freecam and pause

Main controls:
- Control Stick: Move*
- C-Buttons: Yaw/pitch*
- L-Trigger/R-Trigger: Move up/down*
- Start: Pause/unpause (experimental)
- Z-Trigger: Toggle freecam menu

Control stick mode quick-swap:
- D-Pad Up: XZ Translation 
- D-Pad Right: XY Translation 
- D-Pad Down: Yaw/Pitch
- D-Pad Left: FOV

\* The control stick can also edit rotation and FOV depending on the selected mode in the freecam menu. The control scheme will change slightly to compensate when changing modes.
